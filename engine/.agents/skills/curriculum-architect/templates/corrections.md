## 프로젝트 결정

- [규칙 1] (사전 정의) 모든 실습은 devcontainer 안에서 실행한다. 실행 명령은 컨테이너 내부 (Linux 셸) 기준으로 안내한다. / 금지 패턴: 호스트 전용 명령을 실습 실행 절차로 안내 {호스트 실행이 필요한 범위가 있으면 여기에 명시}
- [규칙 2] (사전 정의) 기술 버전은 `CURRICULUM.md`의 확정 버전 매트릭스와 `.devcontainer/`를 따른다. / 금지 패턴: 매트릭스에 없는 버전·런타임 사용, `latest` 태그
- {인터뷰에서 확정한 금지 라이브러리, 아키텍처 경계 등을 `[규칙 N] (사전 정의)` 형식으로 추가}

## 누적 코드 & 아키텍처 규약 (Shared Contract)

> **현재 유효한 규약만 유지합니다.** 스텝이 진행되며 값이 바뀌면 해당 행을 덮어쓰고 `최종 변경 Step`을 갱신합니다. 변경 이력은 git 기록과 해당 스텝의 `04_qa_archive.md`에 남기고, 이 섹션에는 누적하지 않습니다.

### 패키지·모듈 구조

| 항목 | 현재 규약 | 도입 Step | 최종 변경 Step |
| :-- | :-- | :-- | :-- |
| 기본 패키지 / 모듈 루트 | {예: `com.example.order`} | 0 (초기값) | 0 |

### 포트 할당표

| 서비스 | 포트 | 도입 Step | 최종 변경 Step |
| :-- | :-- | :-- | :-- |
| {서비스명} | {포트} | 0 (초기값) | 0 |

### 핵심 도메인 모델·인터페이스

| 이름 | 시그니처 요약 | 위치 | 도입 Step | 최종 변경 Step |
| :-- | :-- | :-- | :-- | :-- |

### 명명 규칙·환경 변수·API 경로
